# Verkaufsseite – so geht sie online

## 1. Anpassen (5 Min.)
- `index.html`: `DIGISTORE_LINK` (kommt 3× vor) durch deinen Digistore24-Bestelllink ersetzen.
- `impressum.html`: gelbe Platzhalter ausfüllen.
- `datenschutz.html`: Platzhalter durch den Text eines Datenschutz-Generators ersetzen (Seite hat kein Tracking und keine Cookies – das macht den Text kurz).

## 2. Kostenlos hosten (eine Option wählen)
- **Netlify Drop:** app.netlify.com/drop öffnen → den Ordner `landingpage/` hineinziehen → fertig, du bekommst eine URL.
- **GitHub Pages:** Pages kann nur `/` oder `/docs` ausliefern – Ordner `landingpage` dafür in `docs` umbenennen, dann Repository-Einstellungen → Pages → Branch + `/docs` wählen (bei privaten Repos ist ein bezahlter GitHub-Plan nötig).
- **Eigene Domain** (z. B. `budgetmitplan.de`, ca. 1 €/Monat) bei Netlify verbinden – wirkt seriöser und lässt sich als Text in die TikTok-Bio schreiben, bevor der Link freigeschaltet ist.

## 3. Bei Digistore24 eintragen
Die URL als „Verkaufsseite“ im Produkt hinterlegen – Digistore verlangt eine Verkaufsseite für die Produktfreigabe.
